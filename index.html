01なぜ「左右の余白が違う」ように見えたのか

padding は左右とも同じ値なのに、見た目が揃っていませんでした。原因は矢印の箱の大きさです。

ボタン内の位置左側右側
padding の指定値24px24px
箱の中に残る空き0px ／ アイコンは箱いっぱいに描かれている6.3px ／ 20px角の箱の中央に幅6.4pxの「〉」
見た目の余白24.0px30.3px

アイコン画像5点を canvas に描いて不透明ピクセルの範囲を測ると、インクは箱の左端（x=0〜2px）から始まっていました。一方「〉」は疑似要素の 1px×8px の棒2本を ±45° 回転したもので、幅は約 6.4px。これが 20px 角の箱の中央に置かれるため、右側に 6.3px の空きが残ります。

対処：矢印の箱を 20px → 8px にして、字形の右端を箱の右端に一致させました。高さ 20px は字形の縦位置（top:3px / bottom:3px）を壊さないため維持しています。結果、見た目の余白は 左 24.0px / 右 24.3px になります。

ボタン内の左右の余白を 10px → 24px にしている理由

今回の修正の主目的です。高さ44pxの丸ピルに対して左右10pxは不足しており、アイコンと矢印が縁に張り付いて見えていました。24pxまで広げることで、アイコンの左側と「〉」の右側にしっかり余白が確保されます。

紫枠（.top_renewal_new）の padding は 20px から変更していません。広げているのは白いボタン（.top_renewal_new a）の内側です。枠の外寸・位置・見出しの位置はすべて現状のままです。

もう1つ見つかった問題：日付の右端が行ごとに揃っていない

「次回案内」カード（グレー）には矢印の <span> がありません。そのため日付が矢印付きの行より 28px 右に出ていました。

行の種類変更前：日付右端の位置変更後

雑貨・コスメ・食（次回案内／矢印なし）10px ← 28pxずれる38px ← 揃う

05入れるときの注意点

この3点だけ先に確認してください。
  • 差分の元ファイルは本番稼働中の CSS です。2026-09-09 に https://cxorder.mse-cloud.jp/consumer/assets/css/top-renewal.css から取得したものを元にしています。リポジトリ側が本番より新しい場合は行番号がずれるので、セレクタ名で該当箇所を探してください。
  • 元ファイルは改行コードが混在しています。1030行中 997行が CRLF、33行が LF です。エディタの設定で保存時に全行を CRLF / LF へ一括変換しないよう注意してください（変換すると差分がファイル全体に広がります）。
  • 新しいメディアクエリは追加していません。このファイルは「PC を基準に書き、@media (max-width: 959px) で SP を上書きする」構成なので、その流儀に合わせています。PC 値をベースに置き、既存の 959px ブロック内で SP 値に戻しています。

07実機で確認してほしいこと

  • PC 右カラムの下端揃え ― 紫枠の高さは 192px のままなので、サイドスライダーとメインバナーの下端は現状どおり揃うはずです。崩れていないか確認してください。
  • SP で紫枠が 40px 伸びること ― 「注目キーワード」以降が 40px 下がります。スクロール感に違和感がないか。
  • 矢印「〉」が右端に寄りすぎていないか ― 数値上は左右揃っていますが、細い線なので体感が違う場合は箱を 10〜12px にすると数px内側に戻せます。
  • 「次回案内」が出る週 ― 週替わりで切り替わるため、実際に切り替わった週に崩れがないか。
  • .top_renewal_new_disabled の padding-right: 38px ― 日付の右端を揃えるための値です。グレーのカード単体で見ると右が空いて見えるので、揃えるより左右対称を優先したい場合はこの1宣言だけ外してください。
